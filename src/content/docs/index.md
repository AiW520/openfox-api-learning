## 学完能做什么

解释项目启动过程，追踪一条核心流程，定位对应函数，并在副本里完成一项有验证方法的小改动。

## 选择阅读路线

**快速入门：** 项目全貌 → 快速上手 → 真实流程 → 实践练习。

**深入阅读：** 架构与数据 → 流程 → 源码精读 → 安全与维护 → 证据核对。

## 课程地图

| 章节 | 完成后的能力 |
|---|---|
| [00 · 先分清两类令牌](courses/new-api/) | 解释控制台管理与模型转发的不同入口，沿三条流程找到源码。 |
| [01 · 环境与可控启动](courses/new-api/start/) | 准备不会接触生产数据的副本，解释构建与启动失败的原因。 |
| [02 · 从页面到数据库的模块边界](courses/new-api/architecture/) | 解释每层输入输出和令牌数据生命周期。 |
| [03 · 三条可逐步核对的真实流程](courses/new-api/flows/) | 追踪查询、创建、删除的请求参数、认证、状态码和页面反馈。 |
| [04 · 精读校验、密钥与失败分支](courses/new-api/code/) | 说明修改校验或错误处理会影响哪些层。 |
| [05 · 安全、工程实践与边界实验](courses/new-api/security/) | 完成一个可验证的输入边界实验，并识别仍需审计的保护。 |
| [06 · 同项目的版本差异](courses/new-api/versions/) | 知道共享课程适用到哪些版本，避免跨版本照抄接口契约。 |
